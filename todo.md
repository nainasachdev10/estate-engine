  ---
  2. Add new env vars to Vercel

  Go to your Vercel project → Settings → Environment Variables. Add:

  ┌───────────────────────────┬─────────────────────────────────────────────────────────┐
  │         Variable          │                          Value                          │
  ├───────────────────────────┼─────────────────────────────────────────────────────────┤
  │ META_WEBHOOK_VERIFY_TOKEN │ Any random string you pick (e.g. realty-engine-2026)    │
  ├───────────────────────────┼─────────────────────────────────────────────────────────┤
  │ META_APP_SECRET           │ From Meta App dashboard → Settings → Basic → App Secret │
  ├───────────────────────────┼─────────────────────────────────────────────────────────┤
  │ AISENSY_SESSION_CAMPAIGN  │ freeform_session (or whatever you name it in step 5)    │
  └───────────────────────────┴─────────────────────────────────────────────────────────┘

  After adding, redeploy: vercel --prod

  ---
  3. Bolna — set your webhook URL

  In your Bolna dashboard → Agent settings → Webhook URL, set:
  https://estate-engine.vercel.app/api/voice/webhook
  This is where call results come back. Without this, calls complete but no follow-up sequences start.
  
  Also set BOLNA_WEBHOOK_SECRET in Vercel to match whatever Bolna signs requests with (check their docs for where to find/set this).

  ---
  4. AiSensy — create a session campaign
  
  In AiSensy dashboard:
  1. Create a new campaign → type: Session Message (not Broadcast)
  2. Name it exactly: freeform_session
  3. This is used for all personalized free-form messages after a lead replies to WhatsApp

  ---
  5. AiSensy — submit WhatsApp templates for Meta approval
  
  You have 6 templates seeded in your DB (wa_templates table). Each needs to be submitted to Meta for approval through AiSensy before they can be sent. In AiSensy:
  1. Go to Templates → Create Template
  2. Create each of these: lead_intro_hi, brochure_followup, site_visit_invite, callback_confirm, gentle_intro
  3. Submit for approval (takes 24–48 hours)
  4. Once approved, update approved = true in your wa_templates table
  
  Until they're approved, only free-form messages (within 24hr reply window) will send.

  ---
  6. Meta Lead Ads webhook setup
  
  1. Go to Meta for Developers (https://developers.facebook.com) → your app → Webhooks
  2. Subscribe to leadgen field on your Facebook Page
  3. Callback URL:
  https://estate-engine.vercel.app/api/leads/meta-webhook?project_id=YOUR_PROJECT_UUID
  3. Replace YOUR_PROJECT_UUID with the UUID of the project this ad set is for (find it in Supabase → projects table)
  4. Verify Token: use the same value you set as META_WEBHOOK_VERIFY_TOKEN
  5. Click Verify — Meta will hit the GET endpoint to confirm, then start sending leads

  For each project/ad campaign, use a different ?project_id= in the URL.
